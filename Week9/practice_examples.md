# 실습 예제 09 — 구현과 분석

## BOJ 2750: 세 가지 기본 정렬

입력 첫 줄은 N, 이후 N개의 정수이며 오름차순으로 한 줄에 하나씩 출력한다. 다음 파일은 각각 독립적으로 실행·제출할 수 있다. 정렬 핵심 구현에는 sorted나 list.sort를 사용하지 않는다. 측정 정보를 표준 출력에 섞지 않는다.

| 알고리즘 | 파일 | 실행 |
|---|---|---|
| 버블 | [boj2750_bubble.py](boj2750_bubble.py) | `python boj2750_bubble.py < input.txt` |
| 선택 | [boj2750_selection.py](boj2750_selection.py) | `python boj2750_selection.py < input.txt` |
| 삽입 | [boj2750_insertion.py](boj2750_insertion.py) | `python boj2750_insertion.py < input.txt` |

예제 입력 리스트 [5,3,1,4,2]를 계측한 결과는 다음과 같다.

| 알고리즘 | 키 비교 | swap | shift |
|---|---:|---:|---:|
| Bubble | 10 | 7 | 0 |
| Selection | 10 | 3 | 0 |
| Insertion | 9 | 0 | 7 |

출력은 모두 [1,2,3,4,5]이다. 실습 PDF 3쪽의 선택 정렬 교환 표시는 4회이지만, 제공된 구현은 min_idx != i인 경우만 교환하므로 실제 교환은 3회이며 마지막 패스의 자기 교환은 수행하지 않는다. 이 문서는 제공 코드의 실제 계측값을 기준으로 기록한다. 삽입 정렬의 7은 교환 횟수가 아닌 오른쪽 이동 횟수이다. 세 파일을 각각 네 가지 로컬 입력으로 실행했으며, 온라인 채점 사이트에 제출한 결과를 주장하지 않는다.

## BOJ 10814: 안정성

같은 나이의 회원은 먼저 가입한 순서를 유지해야 한다. (2,A), (2,B), (1,C)를 나이만 기준으로 정렬할 때 버블·삽입은 [(1,C),(2,A),(2,B)], 교환형 선택은 [(1,C),(2,B),(2,A)]가 된다. 따라서 나이순만 정렬하는 교환형 선택 정렬로는 요구를 보장할 수 없다. 안정 정렬을 사용하거나 비교 키에 (나이, 원래 인덱스)를 포함하면 원하는 순서를 표현할 수 있다. Python의 sorted를 쓰는 응용 풀이에서는 key=lambda record:record[0]으로 나이만 비교하면 원래 동점 순서를 유지하지만, 이것을 기본 정렬 직접 구현의 대체물로 사용하지 않는다.

## BOJ 1377: 종료 패스를 위치 이동으로 계산

왼쪽에서 오른쪽으로 진행하는 버블의 한 패스에서 작은 원소는 최대 한 칸 왼쪽으로 이동한다. 안정 정렬 후 각 원소의 원래 인덱스−새 인덱스의 최댓값에 1을 더하면 종료 확인 패스까지 센 답이 된다. 중복 값은 원래 순서를 유지하도록 (값, 원래 인덱스)로 대응시켜야 한다. [3,2,1]에서는 1이 두 칸 왼쪽으로 이동하므로 답은 3이다. 이는 그 문제의 교환 없는 확인 패스까지 세는 규약이며, 구간을 줄이는 이 노트북의 trace_passes가 모든 입력에서 출력하는 패스 수와 동일한 정의라고 가정하지 않는다.

## BOJ 1517: 교환 횟수와 역전쌍

역전쌍은 i<j인데 a[i]>a[j]인 인덱스 쌍이다. 같은 값은 포함하지 않으며 인접 역순 원소를 교환할 때 한 쌍이 해소되므로, 버블 정렬의 총 swap 수는 초기 역전쌍 수와 같다. [3,1,4,1,5,9,2]의 역전쌍은 (0,1),(0,3),(0,6),(2,3),(2,6),(4,6),(5,6)의 7개이며 삽입 정렬의 shift 수도 7이다. 큰 입력을 이중 반복으로 세면 Θ(n²)이므로, 병합 단계에서 오른쪽 원소를 꺼낼 때 남은 왼쪽 원소 수를 더하는 O(n log n) 방식으로 확장한다. 이 문서에는 연결 원리와 확인 예제를 정리하고, 이번 주의 기본 정렬 세 가지 구현을 제출 파일로 제공한다.
